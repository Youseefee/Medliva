# خارطة الطريق الحالية

المهام المنفذة وتفاصيل التحقق موثقة في docs/EXECUTION_PLAN.md؛ هذا الملخص يصف الوضع الحالي ولا يحل محل الكود.

| المرحلة | الحالة | النطاق |
|---|---|---|
| أساس التطبيق | مكتملة | Flutter/Dart، العربية والإنجليزية، Supabase Auth، التوجيه حسب الدور |
| المريض والمرافق | مكتملة | الأدوية ومواعيدها، الجرعات والمنبهات المحلية، القياسات، الربط، التنبيهات والطوارئ |
| OCR والتخزين | مكتملة | رفع الصور إلى Supabase Storage الخاص، مسح الروشتة عبر Edge Function ومراجعتها قبل الحفظ |
| التقارير والمخزون | مكتملة | حساب المخزون داخل التطبيق، PDF محلي، وروابط تقرير مؤقتة عبر Supabase |
| نقل الخدمات | مكتملة | نقل وظائف البيانات إلى PostgreSQL/RLS/RPC وEdge Functions وإزالة خدمة API المستقلة وإعداداتها |
| النشر على المتاجر | قيد الانتظار | إعداد التوقيع ومتطلبات المتجر ونشر إصدار إنتاجي |

## المكونات الحالية

- Flutter/Dart لتطبيق Android وiOS.
- Supabase Auth وPostgreSQL/PostgREST وStorage.
- SQL migrations وRLS وRPC في supabase/migrations.
- Edge Functions في supabase/functions.
- GitHub Actions لتحليل Flutter والاختبارات وبناء APK.

## ملاحظات التسليم

- لا تُعدّ الميزات في خطة المنتج منفذة إلا إذا أكدها الكود الحالي والاختبارات.
- سجلات الاختبارات القديمة في docs/EXECUTION_PLAN.md تاريخية؛ استخدم نتائج آخر تحقق للمشروع.
- لا تُنشئ بيانات مرضى تجريبية ضمن seed العام لقاعدة البيانات.
