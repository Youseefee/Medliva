## Snapshot (verified from code, 2026-10-27)

| Area | Status |
|---|---|
| Backend | Supabase Auth, PostgreSQL/PostgREST, RLS, SQL RPCs, private Storage, and Edge Functions. |
| Mobile (`apps/mobile`) | Patient and caregiver app in Flutter/Dart. It uses Supabase directly for authentication, profiles, medical data, storage, and server-side functions. |
| Doctor portal | **Dropped as a web app.** Doctor sees a PDF report generated inside the mobile app (Phase 8). `apps/doctor-portal` stays docs-only. |

## Decisions (fixed — do not re-ask)
| Topic | Decision |
|---|---|
| Doctor view | In-app PDF report (medication history, adherence, vitals) shared via system share sheet. No web portal. |
| Patient id for patient users | From the signed-in user's `users` row (`id`). Caregiver patients come from `get_caregiver_dashboard`. Store selected patient in `currentPatientIdProvider`. |
| Escalation | Missed dose = no adherence log 15 min after scheduled time → caregiver notified. |
| Push notifications | Out of scope for now: alerts are read from Supabase on the caregiver dashboard. `register_device` stores a device token for later FCM support. |
| Approved dependencies | Only in the task that names them: `flutter_local_notifications`, `timezone` (P2.4) · `connectivity_plus` (P2.5) · `image_picker` (P5.1) · `geolocator` (P6.2) · `pdf`, `printing` (P8.2) · `supabase_flutter` (P11.1). |

## Rules for every task
- Checks: Mobile → `cd apps/mobile; flutter analyze; flutter test`. Run Supabase migration/function checks required by the task. Do not run removed backend checks.
- Every new UI string in **both** `lib/l10n/app_ar.arb` and `app_en.arb`, then `flutter gen-l10n`. Min tap target 48dp, body text ≥18sp, RTL-safe (`EdgeInsetsDirectional`), never color-only meaning.
- Mobile feature layout: `lib/features/<name>/{data,domain/models,presentation/{screens,widgets}}`.
- **Reference pattern** to copy: `features/auth/data/auth_repository.dart` (Supabase repository), `features/auth/presentation/auth_notifier.dart` (Riverpod notifier), `features/auth/domain/models/user.dart` (model + fromJson). Tests use `mocktail`.
- Keep Flutter model fields aligned with Supabase columns and RPC arguments; read the relevant SQL migration before changing a repository.
- Keep Flutter repositories ↔ SQL migrations/RLS/RPCs ↔ Edge Functions ↔ tests ↔ `docs/API_SPEC.md` aligned.
- No dependencies beyond the Decisions table. Do not commit unless the task says so.
