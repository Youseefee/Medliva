# الأمان والخصوصية

| المجال | الإجراء |
|---|---|
| النقل | HTTPS/TLS 1.3 فقط، WSS للـ WebSocket |
| المصادقة | Supabase Auth بالبريد وكلمة المرور؛ SDK الرسمي يرسل جلسة المستخدم إلى PostgREST وEdge Functions |
| الصلاحيات | RLS تقصر بيانات المريض على حسابه والمرافق المرتبط؛ عمليات SOS والأجهزة ومشاركة التقرير تمر عبر دوال تتحقق من المستخدم الحالي |
| التخزين | صور الروشتات والأدوية في buckets خاصة؛ دالة OCR تقرؤها بجلسة المستخدم نفسها وتخضع لسياسات Storage RLS، ولا تحفظ نتيجة المسح |
| OCR | `scan-prescription` تتطلب JWT صالحًا؛ مفتاح `GEMINI_API_KEY` محفوظ كسر في Supabase Edge Functions ولا يصل إلى Flutter |
| روابط الطبيب | رمز عشوائي 32 بايت، يُحفظ SHA-256 فقط، صلاحية من ساعة إلى 30 يوماً؛ Edge Function تتحقق من الرمز والانتهاء والإلغاء قبل إرجاع التقرير وتزيد عداد المشاهدات |
| الحماية | تحقق من نطاقات الإحداثيات وطول ملاحظة SOS ونطاق انتهاء مشاركة التقرير؛ أسرار الخادم تبقى في بيئة Supabase ولا تصل إلى Flutter |
| الأسرار | `.env` خارج Git، GitHub Secrets، تدوير المفاتيح |
| الخصوصية | Consent صريح، حذف الحساب والبيانات عند الطلب، عدم إرسال هوية المريض للـ LLM؛ لا تُضاف الأدوية إلا بعد مراجعة المستخدم وتأكيده |
| المرجعية | قانون حماية البيانات المصري 151/2020، مبادئ HIPAA/GDPR |

> ⚠️ إخلاء مسؤولية طبي: التطبيق أداة مساعدة ولا يغني عن الطبيب؛ الـ AI يقترح والإنسان يؤكد.
