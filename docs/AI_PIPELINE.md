# مسارات الذكاء الاصطناعي

## مسح الروشتة

1. يختار المستخدم صورة من الكاميرا أو المعرض في Flutter.
2. يرفع التطبيق الصورة إلى bucket prescriptions الخاص في Supabase Storage.
3. يستدعي Flutter Edge Function scan-prescription بجلسة المستخدم ومسار الصورة.
4. تتحقق الدالة من JWT، وتقرأ الصورة والكتالوج بنطاق RLS للمستخدم، ثم تستدعي Gemini Vision باستخدام GEMINI_API_KEY المحفوظ في أسرار Supabase.
5. تعيد الدالة اقتراحات منظمة للمراجعة؛ لا تنشئ دواءً ولا تحفظ نتيجة OCR.
6. يراجع المستخدم الأسماء والجرعات ويؤكد الاختيارات قبل أن ينشئ التطبيق الأدوية عبر Supabase.

عند فقد المفتاح أو فشل OCR، تعيد الدالة قائمة آمنة لا تخترع أدوية. يبقى القرار النهائي للمستخدم.

## تصنيف القياسات

تحسب دالة PostgreSQL record_vital مستوى القراءة وتخزنها. إذا كانت القراءة حرجة، تُنشأ خانة التنبيه في العملية نفسها. تُعرض النتيجة للمريض والمرافق المخول وفق RLS وRPC.

## حدود الخصوصية

- لا ترسل هوية المريض لمزود OCR إلا البيانات اللازمة لمعالجة الصورة.
- الصور في مخازن خاصة، والوصول عبر جلسة المريض أو المرافق المصرح.
- لا تُحفظ اقتراحات الذكاء الاصطناعي كسجلات طبية قبل التأكيد.
- مفاتيح الخدمات الخارجية لا تدخل تطبيق Flutter ولا المستودع.
