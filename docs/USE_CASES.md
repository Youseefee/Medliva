# حالات الاستخدام (Use Cases)

> المرجع الكامل: [original/CareElder_UseCases_and_Features_AR.html](original/CareElder_UseCases_and_Features_AR.html)

## الممثلون
- **المريض (Senior):** 65+، مهارات تقنية محدودة، ضعف نظر محتمل.
- **المرافق (Caregiver):** ابن/ابنة غالباً في الشغل، عايز يطمن.
- **الطبيب:** يشوف التقرير بدون تثبيت أي تطبيق.
- **النظام:** محركات التصعيد والمخزون.

---

## UC-01 منبه الدواء الصارم — Must
1. في الموعد: إشعار Full-Screen فوق شاشة القفل + نغمة متصاعدة + TTS: "يا حاج إبراهيم، ميعاد قرص الضغط، قرص واحد بعد الأكل".
2. صورة القرص + زرين كبار: **أخدته ✅** / **بعدين ⏰ (غفوة 10 د)**.
3. التأكيد يتسجل محلياً ثم يتزامن.
- **قبول:** يرن بدون إنترنت، في وضع Doze، وبعد Restart الهاتف.

## UC-02 مسح الروشتة بالـ AI — Must
1. تصوير → قص/تحسين الصورة → رفع.
2. LLM Vision يرجّع JSON (اسم تجاري، تركيز، تكرار، علاقة بالأكل، مدة).
3. مطابقة مع قاعدة الأدوية المصرية.
4. بطاقة تأكيد قابلة للتعديل؛ الحقول < 85% ثقة متعلّمة.
5. بعد الموافقة: إنشاء المواعيد + المخزون تلقائياً.

## UC-03 القياسات بالصوت — Must
1. زر ميكروفون كبير → "الضغط النهارده 135 على 85".
2. STT → استخراج النوع والقيم → تأكيد صوتي.
3. فرز طبي:

| الحالة | الضغط | السكر الصائم |
|---|---|---|
| 🟢 طبيعي | < 120/80 | 70–110 |
| 🟡 حدّي | 130–139 / 80–89 | 111–140 |
| 🔴 حرج | ≥ 180 أو ≤ 90 انقباضي | < 70 أو > 250 |

4. الحرج: إرشاد صوتي مُطمئن + تنبيه فوري للمرافق.

## UC-04 متابعة المرافق والتصعيد — Must
- Timeline لحظي للجرعات، كروت القياسات + متوسط 7 أيام، رسائل صوتية من الأحفاد تشتغل مع المنبه، تعديل الأدوية عن بُعد.
- **سلّم التصعيد:** 0 د منبه → +15 د تذكير ثاني → +30 د تنبيه Tier-1 للمرافق → +60 د Tier-2 عاجل مع زر اتصال.

## UC-05 المخزون — Should
- خصم تلقائي مع كل جرعة؛ `تاريخ_النفاد = اليوم + (المتبقي ÷ الجرعات اليومية)`.
- تنبيه عند أقل من 5 أيام + رسالة WhatsApp جاهزة للصيدلية.
- تنبيه قبل انتهاء الصلاحية بـ 30 يوم.

## UC-06 تقرير الطبيب — Must
- نسبة الالتزام، منحنيات الضغط والسكر 30/90 يوم، سجل الجرعات الفائتة وأسبابها، قائمة الأدوية الحالية.
- PDF + QR مشفّر مؤقت يفتح بوابة ويب للقراءة فقط.

## UC-07 زر الاستغاثة — Must
- ضغط مطوّل 3 ثوانٍ → GPS → FCM عالي الأولوية + SMS/مكالمة (Twilio) لجهات الطوارئ.

## UC-08..10 — Could / Won't
- التداخلات الدوائية، مساعد صوتي محادثي، تكامل أجهزة Bluetooth/ساعات.
