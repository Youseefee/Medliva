# 🩺 Medliva Doctor Portal

> **ملاحظة معمارية (MVP):** تم استبدال بوابة الويب المستقلة (`Next.js`) بتوليد ومعاينة ومشاركة تقرير الطبيب بصيغة **PDF** مباشرة من داخل تطبيق الموبايل (`apps/mobile/lib/features/reports/`) اعتماداً على نقطة النهاية `GET /api/v1/patients/{patient_id}/reports/summary`.
> يظل هذا المجلد محجوزاً فقط في حال الرغبة مستقبلاً في إضافة لوحة ويب اختيارية بعد الـ MVP.

## البديل المنفّذ حالياً في التطبيق
- شاشة تقرير الطبيب داخل التطبيق (`/reports/doctor`) مع اختيار الفترة الزمنية.
- بناء ملف PDF يدعم العربية (RTL) ويضم: بيانات المريض، جدول الأدوية النشطة، ملخص وسجل الالتزام، جدول القياسات الحيوية مع تمييز القراءات غير الطبيعية نصياً، وإخلاء المسؤولية الطبية.
- معاينة ومشاركة/طباعة التقرير عبر حزمتي `pdf` و `printing`.
