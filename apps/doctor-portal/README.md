# 🩺 CareElder Doctor Portal (Next.js)

البدء: `npx create-next-app@latest . --ts --tailwind --eslint --app`

> البوابة غير منفذة بعد؛ النسخة الأولى تركز على تقرير الطبيب العام `/r/[token]` فقط.

## الصفحات
- `/r/[token]` — تقرير المريض (قراءة فقط): الالتزام، منحنيات الضغط/السكر، الجرعات الفائتة، الأدوية.
- `/admin` — مؤجل لما بعد الـ MVP.

## الحزم
tailwindcss · shadcn/ui · recharts · @tanstack/react-query · next-intl (RTL)
